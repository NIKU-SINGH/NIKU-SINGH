# Hey, I'm Niku.

I'm a software engineer from India who enjoys building things, contributing to open source, and exploring how software works under the hood.

Lately, I've been spending a lot of time exploring **AI coding agents and developer tools**. I'm particularly interested in coding agent harnesses, automated code review, codebase understanding, and making coding agents more reliable. I enjoy experimenting with different tools, understanding their internals, and occasionally building my own.

I've been involved in open source for a while, starting with the [LFX Mentorship](https://lfx.linuxfoundation.org/tools/mentorship/) at Hyperledger in 2022, followed by [Google Summer of Code 2023](https://summerofcode.withgoogle.com/) with [GitLab](https://gitlab.com/NIKU-SINGH).

### Things I've built

- **[Code Compass](https://github.com/NIKU-SINGH/code-compass)** — Exploring codebase understanding through knowledge graphs.
- **[TabIt](https://github.com/NIKU-SINGH/TabIt)** — A VS Code extension for smart inline code completion, with support for multiple AI models and providers.

- **[Recollect AI](https://recollect-ai.vercel.app/)** — A space to capture, organize, and rediscover information.
- **[IngestFlow](https://github.com/NIKU-SINGH/IngestFlow)** — Experimenting with scalable log ingestion and querying.
